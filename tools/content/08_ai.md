# BehaviourTree
summary: A behaviour tree asset (.elbt): the shared decision logic that many agents run.
see: BTInstance, BehaviourTreeRunner, BehaviourTreeExtensions, BTNode

A behaviour tree describes how an AI decides what to do. Composite nodes ([[Selector]], [[Sequence]]) choose between children, decorators ([[Inverter]], [[Cooldown]], [[If]]) change how one child runs, and leaves call **your script's methods** by name ([[ActionNode]], [[ConditionNode]]).

Trees are made in the editor's **Behaviour Tree** window and saved as `.elbt` JSON files. One tree is shared by every agent that runs it, and each agent keeps its own progress in a [[BTInstance]]. The easiest way to run one is the [[BehaviourTreeRunner]] component, or one line in your script: `this.RunBehaviourTree("Assets/AI/Guard.elbt")`.

Leaf methods are found by name on the agent script:

- **Actions** return `BTStatus` (Running while busy), `bool` (true = Success), or `void` (Success). They may take a [[BTContext]].
- **Conditions** are `bool` methods, fields or properties, or blackboard keys.
- **Scores** for utility choices are `float` methods, fields or properties (0..1).

## Members
path: The project path the tree was loaded from.
root: The top node of the tree.
nodeCount: How many nodes the tree has.
Load: The tree at a project path such as "Assets/AI/Zombie.elbt", loaded once and cached. Null when there is no such file.
Reload: Forgets every cached tree, so the next Load reads the files again (after editing them).
Parse: Builds a tree from .elbt JSON text.
@json: The tree as JSON: `{ "root": { "type": ..., "props": {...}, "children": [...] } }`.
Instance: Makes an agent of this tree: its own blackboard and progress. Tick it every frame.
@agent: The script whose methods the leaves call.
@owner: The agent's GameObject (for the editor's live view).

## Example: A guard tree in JSON
file: Assets/AI/Guard.elbt
The tree file the editor saves: a Selector that chases when it sees the player and patrols otherwise.
```json
{
  "root": {
    "type": "Selector",
    "children": [
      { "type": "Sequence", "children": [
        { "type": "Condition", "props": { "condition": "SeesPlayer" } },
        { "type": "Action", "props": { "action": "Chase" } }
      ]},
      { "type": "Sequence", "children": [
        { "type": "Action", "props": { "action": "GoToNextWaypoint" } },
        { "type": "Wait", "props": { "seconds": 2, "random": 1 } }
      ]}
    ]
  }
}
```

## Example: The agent script the tree calls
file: Scripts/Guard.cs
The leaves above call these methods by name. `Chase` and `GoToNextWaypoint` return Running until they are done.
```csharp
using System.Collections.Generic;
using Elintria;
using Elintria.AI;

public class Guard : ElintriaScript
{
    public GameObject player;
    public List<GameObject> waypoints = new List<GameObject>();
    public float sightRange = 12f;
    int next;

    public override void Update() { this.RunBehaviourTree("Assets/AI/Guard.elbt"); }

    [BTCondition] bool SeesPlayer() =>
        player != null && Vector3.Distance(player.transform.position, transform.position) < sightRange;

    [BTAction] BTStatus Chase()
    {
        NavAgent.Of(gameObject).SetDestination(player.transform.position);
        return SeesPlayer() ? BTStatus.Running : BTStatus.Success;
    }

    [BTAction] BTStatus GoToNextWaypoint()
    {
        if (waypoints.Count == 0) return BTStatus.Failure;
        NavAgent a = NavAgent.Of(gameObject);
        Vector3 goal = waypoints[next].transform.position;
        if (a.destination != goal) a.SetDestination(goal);
        if (a.remainingDistance > 0.5f) return BTStatus.Running;
        next = (next + 1) % waypoints.Count;
        return BTStatus.Success;
    }
}
```

## Example: Loading and running a tree by hand
file: Scripts/ManualTree.cs
`Load` caches the tree; `Instance` makes this agent's own copy of its progress.
```csharp
using Elintria;
using Elintria.AI;

public class ManualTree : ElintriaScript
{
    public string treePath = "Assets/AI/Worker.elbt";
    BTInstance brain;

    public override void Start()
    {
        BehaviourTree tree = BehaviourTree.Load(treePath);
        if (tree == null) { Debug.LogError("No tree at " + treePath); return; }
        brain = tree.Instance(this, gameObject);
        brain.blackboard.Set("energy", 1f);
    }

    public override void Update()
    {
        if (brain == null) return;
        BTStatus r = brain.Tick();
        if (r == BTStatus.Failure) Debug.Log(name + ": nothing to do");
    }

    void Work() { brain.blackboard.Set("energy", brain.blackboard.Float("energy") - 0.01f); }
}
```

# BTInstance
summary: One agent's progress through a behaviour tree, with its own blackboard.
see: BehaviourTree, Blackboard, BTStatus

[[BehaviourTree.Instance]] returns a `BTInstance`. Call `Tick()` once per frame. It remembers which nodes are running, keeps per-node timers and counters, and owns the agent's [[Blackboard]].

## Members
tree: The tree being run.
agent: The script whose methods the leaves call.
owner: The agent's GameObject.
blackboard: This agent's named values.
tickCount: How many times it has been ticked.
lastResult: What the last Tick returned.
State: The saved state of node `id` (whether it is running, its timer, counter and so on).
@id: A node's id.

## Example: Ticking at a lower rate
file: Scripts/SlowThinker.cs
Distant or unimportant agents can think a few times a second instead of every frame.
```csharp
using Elintria;
using Elintria.AI;

public class SlowThinker : ElintriaScript
{
    public float thinksPerSecond = 4f;
    BTInstance bt;
    float next;

    public override void Start() { bt = BehaviourTree.Load("Assets/AI/Villager.elbt").Instance(this, gameObject); }

    public override void Update()
    {
        if (Time.time < next) return;
        next = Time.time + 1f / thinksPerSecond;
        bt.Tick();
    }
}
```

# BehaviourTreeRunner
summary: A component that runs a behaviour tree on its object, calling the methods of another script there.
see: BehaviourTree, BTInstance

Add **Behaviour Tree Runner**, set `tree` to an `.elbt` path, and it ticks that tree every frame. The tree's leaves call methods on the first other script on the object, or on the script whose class name you put in `agent`. You don't need any code in the agent script beyond the methods themselves.

## Members
tree: The tree to run, such as "Assets/AI/Zombie.elbt".
agent: The class name of the script whose methods the tree calls. Empty: the first other script on the object.
Agent: The running agent (its blackboard, Reset and so on), or null before Start.

## Example: A zombie with no Update of its own
file: Scripts/Zombie.cs
Put a Behaviour Tree Runner with `tree` = "Assets/AI/Zombie.elbt" on the same object. This script only provides the leaves.
```csharp
using Elintria;
using Elintria.AI;

public class Zombie : ElintriaScript
{
    public float smellRange = 20f;
    GameObject player;

    public override void Start() { player = GameObject.FindWithTag("Player"); }

    bool SmellsPlayer() => player != null && Vector3.Distance(player.transform.position, transform.position) < smellRange;
    bool InReach() => player != null && Vector3.Distance(player.transform.position, transform.position) < 1.5f;

    BTStatus Shamble()
    {
        NavAgent.Of(gameObject).SetDestination(player.transform.position);
        return InReach() ? BTStatus.Success : BTStatus.Running;
    }

    void Bite() { player.SendMessage("ApplyDamage", 15f); }
}
```

# BehaviourTreeExtensions
summary: The one-line way to run a behaviour tree from your own script's Update.
see: BehaviourTree, BehaviourTreeRunner

Call `this.RunBehaviourTree(path)` in your script's `Update`. The first call makes an agent of the tree for this script, and each call ticks it. The tree's leaves call this script's methods.

## Members
RunBehaviourTree: Ticks the tree at `path` for this script, making its agent on the first call. A different path starts a fresh agent.
@script: The script that runs the tree (written as `this`).
BehaviourTreeAgent: This script's agent of `path` (for its blackboard or Reset), or null if it has not run yet.

## Example: Minimal AI in one line

```csharp
    BTStatus Peck() { transform.Rotate(10f * Time.deltaTime, 0f, 0f); return BTStatus.Success; }
    bool Scared() => Physics.CheckSphere(transform.position, 3f);
}
```

# Blackboard
summary: Named values an agent's behaviour tree reads and writes: its short-term memory.
see: BTInstance, SetValue, ConditionNode

Each [[BTInstance]] has its own `Blackboard`. Scripts and the tree's [[SetValue]] nodes store values under names. Conditions and utility scores can read a blackboard key directly as well as a method.

## Members
Set: Stores `value` under `key`.
Has: True when `key` has a value.
Get: The value stored under `key` (null when none), or with `Get<T>` typed, falling back to `def`.
Float: The value under `key` as a float (bools count as 0 or 1), or `def`.
All: Every key and value.

## Example: Remembering where the player was last seen
file: Scripts/Hunter.cs
```csharp
using Elintria;
using Elintria.AI;

public class Hunter : ElintriaScript
{
    const string Tree = "Assets/AI/Hunter.elbt";
    public GameObject player;

    public override void Update()
    {
        BTInstance bt = this.BehaviourTreeAgent(Tree);
        if (bt != null && CanSee()) bt.blackboard.Set("lastSeen", player.transform.position);
        this.RunBehaviourTree(Tree);
    }

    bool CanSee() => Physics.Linecast(transform.position, player.transform.position, out RaycastHit h) && h.gameObject == player;

    BTStatus Investigate(BTContext c)
    {
        if (!c.blackboard.Has("lastSeen")) return BTStatus.Failure;
        Vector3 spot = c.blackboard.Get<Vector3>("lastSeen");
        NavAgent.Of(gameObject).SetDestination(spot);
        return Vector3.Distance(transform.position, spot) > 1f ? BTStatus.Running : BTStatus.Success;
    }
}
```

```csharp
    void Sleep(BTContext c) { c.blackboard.Set("tired", 0f); }
}
```

# BTContext
summary: What a node or an action method receives when it runs: the agent, its blackboard and the time.
see: Blackboard, BTInstance, ActionNode

An action method may take a `BTContext` as its single parameter to reach the agent's blackboard, the instance and the timing.

## Members
agent: The script the tree is running for.
blackboard: The agent's blackboard.
instance: The agent's BTInstance.
deltaTime: Seconds since the last tick.
time: The current game time.

## Example: A timed action using the context
file: Scripts/Channel.cs
```csharp
using Elintria;
using Elintria.AI;

public class Channel : ElintriaScript
{
    public override void Update() { this.RunBehaviourTree("Assets/AI/Mage.elbt"); }

    BTStatus ChannelSpell(BTContext c)
    {
        float t = c.blackboard.Float("channel") + c.deltaTime;
        c.blackboard.Set("channel", t);
        if (t < 2f) return BTStatus.Running;
        c.blackboard.Set("channel", 0f);
        Debug.Log("Fireball!");
        return BTStatus.Success;
    }
}
```

# BTNode
summary: The base of every behaviour tree node: its id, type, properties and children.
see: BehaviourTree, BTStatus, Decorator

Every node in a tree is a `BTNode`. Its `type` is the node kind, `props` holds its settings from the `.elbt` file, and `children` holds the nodes under it. The helpers `Str`, `Num` and `Flag` read a property with a default. You can derive your own node for trees built in code: override `Run` (and optionally `Enter`, `Exit` and `OnAbort`).

## Members
id: The node's number within its tree.
type: The node kind, such as "Selector" or "Action".
x: Where the editor drew the node.
y: Where the editor drew the node.
children: The nodes under this one.
props: The node's settings, from its "props" in the .elbt file.
Str: The property `k` as a string, or `def`.
@k: The property's name.
Num: The property `k` as a number, or `def`.
Flag: The property `k` as a bool, or `def`.
Enter: Called when the node starts running (not when it resumes while Running).
@c: The tick's context.
@s: This node's saved state for the agent.
Run: The node's work for this tick. Return Success, Failure or Running.
Exit: Called when the node finishes, with its result.
@r: The result it finished with.
OnAbort: Called when a higher-priority branch interrupts the node while it is running.

## Example: A custom "chance" node
file: Scripts/ChanceNode.cs
A node that succeeds with a probability from its props, usable in trees built in code.
```csharp
using Elintria;
using Elintria.AI;

public sealed class ChanceNode : BTNode
{
    protected override BTStatus Run(BTContext c, BTInstance.NodeState s)
    {
        return Random.value < Num("chance", 0.5f) ? BTStatus.Success : BTStatus.Failure;
    }
}
```

## Example: Building a tree in code with a custom node
file: Scripts/CodeTree.cs
```csharp
using Elintria;
using Elintria.AI;

public class CodeTree : ElintriaScript
{
    BTInstance bt;

    public override void Start()
    {
        var chance = new ChanceNode();
        chance.props["chance"] = 0.25f;
        var sneeze = BehaviourTree.Parse(@"{ ""root"": { ""type"": ""Action"", ""props"": { ""action"": ""Sneeze"" } } }").root;

        var seq = new Sequence();
        seq.children.Add(chance);
        seq.children.Add(sneeze);

        bt = new BehaviourTree { root = seq }.Instance(this, gameObject);
    }

    public override void Update() { bt.Tick(); }

    void Sneeze() { Debug.Log("Achoo!"); }
}
```

## Example: Reading a node's settings
file: Scripts/TreeInspector.cs
Walks a loaded tree and prints each node with its props.
```csharp
using Elintria;
using Elintria.AI;

public class TreeInspector : ElintriaScript
{
    public string treePath = "Assets/AI/Guard.elbt";

    public override void Start() { Print(BehaviourTree.Load(treePath).root, 0); }

    void Print(BTNode n, int depth)
    {
        string extra = n.type == "Action" ? " -> " + n.Str("action") : n.type == "Wait" ? " " + n.Num("seconds", 1f) + "s" : "";
        Debug.Log(new string(' ', depth * 2) + "#" + n.id + " " + n.type + extra);
        foreach (BTNode child in n.children) Print(child, depth + 1);
    }
}
```

# BTStatus
summary: What a node reports after a tick: Success, Failure or still Running.
see: BTNode, ActionNode

## Members
Success: The node finished and did what it set out to do.
Failure: The node could not do it.
Running: The node is still busy; it will be ticked again next frame.

## Example: An action that takes time
file: Scripts/OpenChest.cs
```csharp
using Elintria;
using Elintria.AI;

public class OpenChest : ElintriaScript
{
    public GameObject chest;
    float progress;

    public override void Update() { this.RunBehaviourTree("Assets/AI/Looter.elbt"); }

    BTStatus Open(BTContext c)
    {
        if (chest == null) return BTStatus.Failure;
        progress += c.deltaTime;
        if (progress < 1.5f) return BTStatus.Running;
        progress = 0f;
        return BTStatus.Success;
    }
}
```

## Example: bool and void actions
file: Scripts/SimpleActions.cs
A `bool` action reports Success or Failure; a `void` action always succeeds.
```csharp
using Elintria;
using Elintria.AI;

public class SimpleActions : ElintriaScript
{
    public int ammo = 3;

    public override void Update() { this.RunBehaviourTree("Assets/AI/Shooter.elbt"); }

    bool Shoot() { if (ammo <= 0) return false; ammo--; return true; }   // Success / Failure
    void Reload() { ammo = 3; }                                           // always Success
}
```

## Example: Reacting to the tree's result
file: Scripts/ResultWatcher.cs

# Utility
summary: Utility AI maths: how a child's score is computed and the response curves applied to it.
see: UtilitySelector, BTScoreAttribute

A [[UtilitySelector]] child's utility is its `weight` multiplied by each of its considerations. A consideration (`score`, `score2`, ... up to 8) is a method, property or blackboard key. Its raw value is mapped from `scoreMin`..`scoreMax` to 0..1 and passed through a curve (`scoreCurve`): `linear`, `inverse`, `quadratic`, `inverseQuadratic`, `sqrt`, `logistic`, `step` or `bell`.

## Members
Score: The utility of node `n` for this agent: its weight times every consideration.
@n: The child node.
@c: The tick's context.
Curve: Applies the response curve `kind` to `t` (0..1).
@kind: linear, inverse, quadratic, inverseQuadratic, sqrt, logistic, step or bell.
@t: The input, 0..1.

## Example: Seeing what the curves do
file: Scripts/CurvePlot.cs
```csharp
using Elintria;
using Elintria.AI;

public class CurvePlot : ElintriaScript
{
    public override void Update()
    {
        string[] kinds = { "linear", "inverse", "quadratic", "sqrt", "logistic", "step", "bell" };
        for (int k = 0; k < kinds.Length; k++)
            for (int i = 0; i < 50; i++)
            {
                float y0 = Utility.Curve(kinds[k], i / 50f), y1 = Utility.Curve(kinds[k], (i + 1) / 50f);
                ScreenGUI.Line(new Vector2(40 + i * 4, 120 + k * 70 - y0 * 50), new Vector2(44 + i * 4, 120 + k * 70 - y1 * 50), Color.cyan);
            }
    }
}
```

# NodeState
summary: One node's saved state for one agent: running or not, timers, counters and scores.
see: BTInstance, BTNode

Kept per agent and per node by [[BTInstance]], and passed to a node's `Enter`, `Run`, `Exit` and `OnAbort`. Custom nodes use it to remember things between ticks.

## Members
open: True while the node is running (returned Running last tick).
last: The node's last result.
lastTick: The tick it last ran on.
until: A time, used by Wait, Cooldown and TimeLimit.
score: The last utility score (UtilitySelector children).
order: A child order (RandomSelector).

# Selector
summary: Runs its children in order until one does not fail: "try this, else that".
see: Sequence, BTNode, If

A Selector ticks its children from first to last and stops at the first that succeeds or is still running. It fails only when every child fails. It is **reactive**: each tick starts again from the first child, so a higher-priority branch takes over as soon as its condition holds, and the branch it replaces is aborted.

Put the most important behaviour first: flee before fight, fight before patrol.

## Example: Priorities
file: Assets/AI/Soldier.elbt
```json

  { "type": "If", "props": { "condition": "LowHealth" }, "children": [ { "type": "Action", "props": { "action": "TakeCover" } } ] },
  { "type": "If", "props": { "condition": "SeesEnemy" }, "children": [ { "type": "Action", "props": { "action": "Attack" } } ] },
  { "type": "Action", "props": { "action": "Patrol" } }
] } }
```

## Example: Fallback actions
file: Assets/AI/Door.elbt
Try to open the door, else pick the lock, else break it.
```json
{ "root": { "type": "Selector", "children": [
  { "type": "Action", "props": { "action": "OpenDoor" } },
  { "type": "Action", "props": { "action": "PickLock" } },
  { "type": "Action", "props": { "action": "BreakDoor" } }
] } }
```

## Example: Cleaning up when interrupted
file: Scripts/AbortAware.cs
When a selector switches branch, a running action is aborted; a method named `<Action>Abort` is called so it can tidy up.

# UtilitySelector
summary: Runs the child with the highest utility score: needs-driven, weighted AI.
see: Utility, BTScoreAttribute, Blackboard

## Example: A timeout on a door

## Example: The chase method
file: Scripts/Chaser.cs
```csharp
using Elintria;
using Elintria.AI;

public class Chaser : ElintriaScript
{
    public GameObject target;
    public override void Update() { this.RunBehaviourTree("Assets/AI/Chaser.elbt"); }

    BTStatus Chase() { NavAgent.Of(gameObject).SetDestination(target.transform.position); return BTStatus.Running; }

}
```

# If
summary: Runs its child only while a condition holds, and stops it as soon as it no longer does.
see: ConditionNode, Selector, Decorator

`If` checks its `condition` (a method, field, property or blackboard key) every tick. While it holds, the child runs. When it stops holding, the child is aborted and `If` fails. Set `negate` to run the child while the condition does *not* hold.

## Example: Fight only while the enemy is visible
file: Assets/AI/Fighter.elbt
```json
{ "root": { "type": "Selector", "children": [
  { "type": "If", "props": { "condition": "SeesEnemy" }, "children": [ { "type": "Action", "props": { "action": "Fight" } } ] },
  { "type": "Action", "props": { "action": "Search" } }
] } }
```

## Example: Negated, from a blackboard key
file: Assets/AI/Nightwatch.elbt
```json
{ "root": { "type": "If", "props": { "condition": "isDay", "negate": true }, "children": [
  { "type": "Action", "props": { "action": "PatrolWithLantern" } }
] } }
```

## Example: Setting the key from a script
file: Scripts/Nightwatch.cs
```csharp
using Elintria;
using Elintria.AI;

public class Nightwatch : ElintriaScript
{
    const string Tree = "Assets/AI/Nightwatch.elbt";

    public override void Update()
    {
        this.RunBehaviourTree(Tree);
        this.BehaviourTreeAgent(Tree).blackboard.Set("isDay", (Time.time % 120f) < 60f);
    }

    BTStatus PatrolWithLantern() { transform.Rotate(0f, 30f * Time.deltaTime, 0f); return BTStatus.Running; }
}
```

# ActionNode
summary: A leaf that calls one of the agent's methods by name (type "Action" in .elbt files).
see: ConditionNode, BTActionAttribute, BTStatus

The `action` property names a method on the agent script. It returns `BTStatus`, `bool` or `void`, and takes nothing or a [[BTContext]]. If the agent also has a method named `<action>Abort`, it is called when a higher-priority branch interrupts the action.

## Example: An action in a tree
file: Assets/AI/Miner.elbt
```json
{ "root": { "type": "Sequence", "children": [
  { "type": "Action", "props": { "action": "Dig" } },
  { "type": "Action", "props": { "action": "Deposit" } }
] } }
```

## Example: Actions of every shape
file: Scripts/Miner.cs
```csharp
using Elintria;
using Elintria.AI;

public class Miner : ElintriaScript
{
    public int ore;

    public override void Update() { this.RunBehaviourTree("Assets/AI/Miner.elbt"); }

    BTStatus Dig(BTContext c)                 // Running until enough ore
    {
        ore += Random.value < c.deltaTime ? 1 : 0;
        return ore >= 5 ? BTStatus.Success : BTStatus.Running;
    }

    bool Deposit() { if (ore == 0) return false; ore = 0; return true; }
    void DigAbort() { Debug.Log("Stopped digging"); }
}
```

## Example: A missing method is reported, not fatal
file: Scripts/MissingAction.cs
An Action whose method does not exist fails, and the editor shows a warning naming it.
```csharp
using Elintria;
using Elintria.AI;

public class MissingAction : ElintriaScript
{
    public override void Update()
    {
        // The tree names "Fly", which this script lacks: that node simply fails.
        this.RunBehaviourTree("Assets/AI/Bird.elbt");
    }
}
```

# ConditionNode
summary: A leaf that tests a condition: a bool method, field, property or blackboard key (type "Condition").
see: If, ActionNode, BTConditionAttribute

It succeeds when the `condition` holds and fails when it does not. With `negate` set, it is the other way round. Unlike [[If]], it has no child. Put it at the start of a [[Sequence]] to guard the steps after it.

## Example: A guard condition in a sequence
file: Assets/AI/Healer.elbt
```json
{ "root": { "type": "Sequence", "children": [
  { "type": "Condition", "props": { "condition": "HasPotion" } },
  { "type": "Condition", "props": { "condition": "FullHealth", "negate": true } },
  { "type": "Action", "props": { "action": "DrinkPotion" } }
] } }
```

## Example: Conditions from methods and fields
file: Scripts/Healer.cs
```csharp
using Elintria;
using Elintria.AI;

public class Healer : ElintriaScript
{
    public int potions = 2;
    public float health = 40f;
    public bool FullHealth => health >= 100f;   // a property works

    public override void Update() { this.RunBehaviourTree("Assets/AI/Healer.elbt"); }

    bool HasPotion() => potions > 0;
    void DrinkPotion() { potions--; health = Mathf.Min(100f, health + 50f); }
}
```

## Example: A blackboard key as the condition
file: Assets/AI/Sleeper.elbt
```json
{ "root": { "type": "Sequence", "children": [
  { "type": "Condition", "props": { "condition": "heardNoise" } },
  { "type": "Action", "props": { "action": "WakeUp" } }
] } }
```

# Wait
summary: A leaf that waits a number of seconds, plus an optional random extra, then succeeds.
see: Cooldown, Sequence

It returns Running for `seconds`, plus a random extra of up to `random` seconds, then Success.

## Example: Pause between steps

```json
  { "type": "Action", "props": { "action": "LookLeft" } },
  { "type": "Wait", "props": { "seconds": 2 } },
  { "type": "Action", "props": { "action": "LookRight" } },
  { "type": "Wait", "props": { "seconds": 2 } }
] } ] } }
```

## Example: Natural-feeling random waits

```json
{ "root": { "type": "Sequence", "children": [
  { "type": "Wait", "props": { "seconds": 1, "random": 4 } },
  { "type": "Action", "props": { "action": "Chirp" } }
] } }
```

## Example: The sentry's methods

```csharp
using Elintria;
```

# SetValue
summary: A leaf that writes a value into the agent's blackboard, then succeeds.
see: Blackboard, ConditionNode

It sets the blackboard's `key` to `value`, which can be a number, text, true/false or null.

## Example: Raising an alarm flag
file: Assets/AI/Alarm.elbt
```json
{ "root": { "type": "Sequence", "children": [
  { "type": "Condition", "props": { "condition": "SeesIntruder" } },
  { "type": "SetValue", "props": { "key": "alarm", "value": true } },
  { "type": "Action", "props": { "action": "SoundAlarm" } }
] } }
```

## Example: Choosing a mode by name
file: Assets/AI/Moods.elbt
```json
{ "root": { "type": "Selector", "children": [
  { "type": "Sequence", "children": [
    { "type": "Condition", "props": { "condition": "Insulted" } },
    { "type": "SetValue", "props": { "key": "mood", "value": "angry" } } ] },
  { "type": "SetValue", "props": { "key": "mood", "value": "calm" } }
] } }
```

## Example: Reading the value in a script
file: Scripts/Moods.cs
```csharp
using Elintria;
using Elintria.AI;

public class Moods : ElintriaScript
{
    public bool insulted;
    const string Tree = "Assets/AI/Moods.elbt";

    public override void Update()
    {
        this.RunBehaviourTree(Tree);
        string mood = this.BehaviourTreeAgent(Tree).blackboard.Get<string>("mood", "calm");
        ScreenGUI.Text(20, 20, name + " is " + mood);
    }

    bool Insulted() => insulted;
}
```

# SubTree
summary: Runs another tree file in place, so trees can be shared and reused (type "SubTree").
see: BehaviourTree

The `tree` property names another `.elbt` file. Its nodes run as part of this tree, for the same agent, with the same blackboard.

## Example: Shared combat logic
file: Assets/AI/Orc.elbt
```json
{ "root": { "type": "Selector", "children": [
  { "type": "SubTree", "props": { "tree": "Assets/AI/Shared/Combat.elbt" } },
  { "type": "Action", "props": { "action": "Wander" } }
] } }
```

## Example: Reusing the same sub-tree in another creature
file: Assets/AI/Goblin.elbt
```json
{ "root": { "type": "Selector", "children": [
  { "type": "If", "props": { "condition": "Scared" }, "children": [ { "type": "Action", "props": { "action": "RunAway" } } ] },
  { "type": "SubTree", "props": { "tree": "Assets/AI/Shared/Combat.elbt" } },
  { "type": "Action", "props": { "action": "Steal" } }
] } }
```

## Example: Reloading after editing a sub-tree
file: Scripts/ReloadTrees.cs
```csharp
using Elintria;
using Elintria.AI;

public class ReloadTrees : ElintriaScript
{
    public override void Update()
    {
        if (Input.GetKeyDown(KeyCode.F5))
        {
            BehaviourTree.Reload();   // sub-trees are read again too
            Debug.Log("Behaviour trees reloaded");
        }
    }
}
```
