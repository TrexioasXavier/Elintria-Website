using Elintria;

public class Spinner : ElintriaScript
{
    public float degreesPerSecond = 90f;   // editable in the Inspector
    public Vector3 axis = Vector3.up;

    public override void Update()
    {
        transform.Rotate(axis, degreesPerSecond * Time.deltaTime);

        if (Input.GetKeyDown(KeyCode.Space))
            Debug.Log(name + " is spinning at " + degreesPerSecond + " deg/s");
    }
}
What's inside

Everything a game needs, in one editor

Scene editing, scripting, physics, rendering, animation and AI all run in the same tool. You test in Play mode and ship a standalone build.

A familiar editor

Hierarchy, Inspector, Scene and Game views, a Project window, docking, and windows you can pop out. If you've used Unity, the layout and shortcuts will feel familiar.

C# and C++ scripting

Write C# scripts on .NET 8 or native C++ components. Public fields show up in the Inspector. Includes a built-in script editor, debugger and live reload.

Physics

Rigidbodies and colliders, including mesh and terrain colliders. A capsule CharacterController, raycasts, sphere and capsule casts, triggers and collision callbacks.

Terrain, foliage and water

Sculpt and paint heightmap terrain. Paint grass that bends in the wind, place trees, add water with waves, shore foam and buoyancy, and build roads from splines.

Animation and IK

An Animator with state machines and blend trees, plus an Animation window. Skinned FBX models, look-at IK, two-bone IK, foot IK and ragdolls.

AI that thinks

Behaviour trees with utility scoring, navigation meshes with crowds and off-mesh links, and ML agents you can train inside the editor.

Multiplayer

A host-authoritative netcode layer with client prediction, network variables and RPCs. It connects over LAN, a relay, or Steam.

Procedural tools

Noise, Poisson-disk sampling, dungeon and cave generators, wave function collapse and L-systems, all callable from your scripts.

One-click builds

Ship a standalone game with its assets packed into an encrypted bundle. Build from the command line or a cloud workflow, and upload to Steam.

Scripts/Turret.cs
using Elintria;

public class Turret : ElintriaScript
{
    public GameObject target;
    public float range = 25f;

    public override void Update()
    {
        if (target == null) return;
        Vector3 to = target.transform.position - transform.position;
        if (to.magnitude > range) return;

        transform.rotation = Quaternion.RotateTowards(
            transform.rotation, Quaternion.LookRotation(to), 120f * Time.deltaTime);

        if (Physics.Raycast(transform.position, transform.forward, out RaycastHit hit, range))
            Debug.DrawLine(transform.position, hit.point, Color.red);
    }
}
